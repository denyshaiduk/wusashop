# WUSAshop

Інтернет-магазин WUSAshop: преміальний дизайн-фронтенд + власний Node.js бекенд з адмін-панеллю, каталогом товарів у базі даних, онлайн-оплатою LiqPay та розрахунком доставки Нова Пошта.

## Швидкий старт

```bash
npm install
copy .env.example .env    # на macOS/Linux: cp .env.example .env
```

Відкрийте `.env` і заповніть:

- `ADMIN_PASSWORD` — пароль для входу в адмін-панель.
- `SESSION_SECRET` — будь-який випадковий рядок.
- `LIQPAY_PUBLIC_KEY` / `LIQPAY_PRIVATE_KEY` — ключі магазину з [кабінету LiqPay](https://www.liqpay.ua/account/develop) (без них кнопка онлайн-оплати поверне зрозумілу помилку, а не впаде).
- `NOVA_POSHTA_API_KEY` — ключ API з [кабінету Нової Пошти](https://developers.novaposhta.ua/) (без нього поле міста покаже помилку завантаження, решта сайту працює).
- `SITE_URL` — публічна адреса сайту (для локальної розробки `http://localhost:3000`).

Запуск сервера:

```bash
npm start
```

Сайт: http://localhost:3000
Адмін-панель: http://localhost:3000/admin

## Публікація на GitHub Pages

У репозиторії є workflow `.github/workflows/deploy-pages.yml`. Після push у гілку `main` відкрийте **Settings → Pages** у GitHub і виберіть **GitHub Actions** як джерело публікації. Файл `CNAME` уже налаштований на `wusashop.com.ua`.

У налаштуваннях DNS домену додайте записи GitHub Pages для apex-домену: `A` на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. Для `www` додайте `CNAME` на `<ваш-акаунт>.github.io`. Після перевірки DNS увімкніть **Enforce HTTPS** у **Settings → Pages**.

GitHub Pages запускає лише статичні файли. Node.js API, адмін-панель, прийом замовлень, оплата, чеки та інтеграція Нової пошти потребують окремого Node.js-хостингу; на Pages вони навмисно не імітуються.

### Розгортання API та адмінки

1. Опублікуйте вітрину з цього репозиторію на GitHub Pages: `https://wusashop.com.ua`.
2. Підготуйте VPS з Docker та Docker Compose. Направте DNS-запис `api` типу `A` на IP VPS і відкрийте порти `80` та `443` у фаєрволі.
3. На сервері клонувуйте репозиторій, виконайте `cp .env.production.example .env.production`, заповніть у ньому нові сильні `ADMIN_PASSWORD` і `SESSION_SECRET`, ключ Нової пошти та реквізити.
4. Запустіть `docker compose up -d --build`. Caddy сам отримає та продовжуватиме HTTPS-сертифікат для `api.wusashop.com.ua`.
5. Адмін-панель стане доступною за адресою `https://api.wusashop.com.ua/admin/`. SQLite і завантажені фотографії зберігаються поза контейнером у папках `data/` та `assets/images/products/`.

У production сервер відмовиться запускатися з демонстраційними `ADMIN_PASSWORD` або `SESSION_SECRET`.

Вітрина автоматично звертається до `https://api.wusashop.com.ua`. Локально вона, як і раніше, працює з `http://localhost:3000`. Дозволені CORS-джерела вже обмежені доменами WUSAshop; не використовуйте `Access-Control-Allow-Origin: *`.

## Що це дає

- **Каталог товарів у базі даних** (вбудований `node:sqlite`, файл `data/wusashop.sqlite`, створюється автоматично при першому запуску з демо-товарами).
- **Адмін-панель** (`/admin`) — вхід за паролем, додавання/редагування/видалення товарів (назва, категорія, опис, ціна, стара ціна, статус, фото), перегляд і зміна статусів замовлень.
- **Кошик і оформлення замовлення** прямо на сайті (localStorage + модальні вікна в дизайні сайту).
- **Доставка Нова Пошта** — автопідбір міста та відділення при оформленні замовлення через офіційне API.
- **Оплата LiqPay** — при оформленні клієнт або оплачує карткою одразу (redirect на LiqPay checkout), або обирає оплату при отриманні. Сервер перевіряє підпис колбека і сам рахує суму замовлення з БД (клієнтським цінам не довіряє).

## Структура

- `index.html`, `assets/` — фронтенд вітрини (дизайн не змінювався, товари тепер підвантажуються з `/api/products`).
- `server/` — Node.js/Express бекенд: БД (`db.js`), маршрути `products`/`orders`/`auth`/`novaposhta`, інтеграція LiqPay (`liqpay.js`) та Нової Пошти (`novaposhta.js`).
- `admin/` — окрема статична адмін-панель (HTML/CSS/JS), стилізована в кольорах сайту.
- `data/` — файл SQLite (не в git).
- `.env` — секрети та ключі (не в git, беріть за зразком `.env.example`).

## Нотатки з безпеки

- Пароль адміна перевіряється на сервері, сесія — httpOnly-кука з підписом (HMAC), а не просто localStorage.
- Ціни замовлення завжди рахуються сервером з БД товарів, а не з даних, надісланих браузером.
- Підпис колбека LiqPay перевіряється (`verifyCallbackSignature`) перед оновленням статусу оплати.
- Завантаження зображень товарів обмежене типом файлу (jpg/png/webp/gif) і розміром (8 МБ).
