# WUSAshop static prototype

Преміальна статична оболонка інтернет-магазину WUSAshop за наданим технічним завданням.

## Як переглянути

Відкрийте `index.html` у браузері напряму або запустіть будь-який локальний статичний сервер у цій папці.

## Структура

- `index.html` - головна сторінка та page-like макети першого етапу: каталог, категорія, картка товару, кошик, оформлення, індивідуальне замовлення, доставка, контакти, стани та дизайн-система.
- `assets/css/styles.css` - темна преміальна дизайн-система, адаптив, модальні вікна, картки, форми і стани.
- `assets/js/app.js` - мобільне меню, пошук, швидке замовлення, обране і лічильник кошика.
- `assets/images/` - локальні згенеровані bitmap-зображення для hero, продуктів, подарункових наборів і майстерні.

## Що підготовлено для наступного етапу

- Семантичні секції з майбутніми ecommerce-точками підключення.
- SEO-основа: title, meta description, Open Graph, Store/Product JSON-LD.
- Компоненти для фільтрів, карток товарів, кошика, checkout, форм, порожніх/помилкових станів.
- Адаптивні мобільні CTA, мобільне меню і sticky-кнопка додавання в кошик.
- Мінімалістичний преміальний режим: приглушена палітра, компактний hero, рівна магазинна сітка, менше декоративних ефектів.
- Адаптація закладена для великих екранів, ноутбуків, планшетів, смартфонів і вузьких мобільних екранів.
